# Implement a task in OpsPilot

Follow this sequence:

1. Read `CLAUDE.md`, relevant `docs/` files, and the code paths involved.
2. Inspect `git status`, current branch, and recent commits.
3. Write a short implementation plan before editing.
4. Implement a minimal complete change with appropriate tests.
5. Run focused tests first, then broader checks when practical.
6. Review the diff for security, tenant isolation, secrets, migrations, and accidental unrelated changes.
7. Report:
   - objective;
   - files changed;
   - tests/checks executed and exact results;
   - known limitations or blockers;
   - suggested next step.

Do not merely describe a solution when the request is to implement it. Do not claim success without command output.
